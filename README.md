# AI Image Generator 🎨

## 📌 Description
This project generates AI images using deep learning.
An AI-powered Image Generator built using Python and Google Colab. 
This project allows users to generate images from text prompts using deep learning models.

## 🚀 Features
- 🧠 Text-to-Image Generation
- 🎨 Creative AI-generated outputs
- ⚡ Fast execution using Google Colab
- 🌐 Simple and user-friendly interface
- 📦 Easy to run and modify

## 🛠️ Technologies Used
- Python 🐍
- Google Colab
- Deep Learning Models (Stable Diffusion / similar)
- Libraries:
  - torch
  - diffusers
  - transformers
  - matplotlib


## ▶️ How to Run

### Option 1: Using Google Colab

1. Open the notebook in Colab  
2. Run all cells step by step  
3. Enter your prompt  
4. View generated image
